# 테스트와 실제 검증 범위

## 실행

```bash
npm test
npm run typecheck
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
```

## 이번 제작에서 실행한 검증

- Vitest/Testing Library: N-back 준비 구간 및 혼동 행렬, 정확한 목표 수, 시드 재현, 회상 순서, 계산 참/거짓, 추론 유일해/모순/다중해, 카드 일정, 난이도, Registry, Repository 저장·백업·복원·충돌·손상·용량 오류, 실제 UI 완료·저장·새 마운트·탭 숨김.
- 모든 주요 게임의 입력/회상/완료 동작에 대한 컴포넌트 테스트. Running Span 실제 마지막 숫자, Complex Span 실제 문자/계산, 궁전 부분 회상, 인출 카드 일정 검증.
- 브라우저: 데스크톱 대시보드, 추론 정식 한 라운드 정답/풀이/결과 저장, 새로고침 후 통계 기록 확인.
- 320/390/768 CSS px iframe에서 반응형 화면 스크린샷과 문서 너비 측정: 가로 넘침 없음.
- 위 3개 대시보드에서 axe-core WCAG 2 A/AA, 2.1 AA, 2.2 AA 자동 검사: 위반 0. 이는 전체 WCAG 준수 인증이 아닙니다.

## 실행하지 않은 검증

- 이 관리 환경에서는 브라우저 조작을 제공된 브라우저 도구로 수행했습니다. Playwright CLI E2E 파일은 작성했으나 여기에서 실행했다고 주장하지 않습니다. GitHub Actions에서 실행하도록 구성했습니다.
- 실제 Android Chrome/iOS Safari, 보조기술 수동 전체 검사, 모든 화면/테마의 자동 접근성 검사, 실제 GitHub Pages URL 검증은 미수행입니다.
- 375/430/1024/1440 너비 자동 검사는 CI E2E에 작성했으며 현재 관찰한 320/390/768과 구분합니다.

최초 v1에 구버전 migration 변환은 없습니다. 현재 스키마 보존과 미지원 버전 거절을 테스트하며 새 스키마 도입 시 실제 변환 테스트를 추가합니다. 테스트의 무작위 생성은 고정 seed로 재현합니다. 타이머는 가짜 시계와 React act로 검사합니다.

## 로직 재검토 후 회귀 검증

총 37개 테스트 통과. 추가 11개는 기억 모드 응답 잠금/해제, 연습 조건 숨김, 자극 사이 빈 구간, N-back 연습 판정, 궁전 자동 암기 종료, 계산 타임아웃, 모르는 자리 회상, 비연속 난이도 기록, 장소 수 상한, 어려운 카드의 재학습, 누락 이름 판정 오류를 검증합니다. 기존 단순 정상 흐름만으로는 놓쳤던 조건 경계와 오답 동작을 추가했습니다.

## 모바일 화면 점검 (2026-11-15)

- Chrome의 동일 출처 iframe으로 320/360/390/768px 레이아웃 검사. 스크롤바가 있는 화면은 실제 콘텐츠 폭이 15px 더 좁음.
- 대시보드, 전체 훈련, 6종 설정, 기록, 근거, 설정 화면: 가로 넘침 없음.
- 5종 훈련 시작 화면은 네 폭 모두 검사. 인출 연습은 320px에서 긴 질문·영문 정답으로 확인.
- 320px에서 Complex Span 7자리 회상·오답 확인·결과, N-back 정식 훈련의 정사각형 격자 확인.
- 모바일 하단 메뉴 터치 영역 64×48px(320px 프레임), 설정 주요 버튼 최소 높이 44px 확인.
- 다크 모드의 보조 글자 색을 라이트 전용 규칙이 덮어쓰던 문제 수정. 경로 이동 후 이전 스크롤 위치가 남던 문제 수정; 실제 스크롤 후 메뉴 이동 시 top=0 확인.
- 실제 iOS Safari, Android 브라우저, 가상 키보드·노치·회전 동작은 검증하지 않음.
