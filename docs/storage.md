# 저장과 복원

키 `cognitive-lab:v1`에 스키마 v1 JSON을 보관합니다. 게임 결과는 Promise 계약의 LocalStorageRepository로 저장합니다. 지원 브라우저에서는 Web Locks로 여러 탭의 read-modify-write를 직렬화합니다. Web Locks가 없는 환경에서는 단일 탭 사용을 권장하며 완전한 동시 쓰기 보장은 없습니다.

- `saveSession`은 ID 기준 upsert. 중복 완료 호출을 UI ref와 ID로 방어합니다.
- `read` 실패 시 원본을 삭제하지 않습니다. 설정에서 원본 다운로드 후 복원할 수 있습니다.
- 쓰기 실패 시 사용자에게 알리고 결과 화면에서 다시 저장할 수 있습니다.
- 백업은 5MB 이하 파일만 읽고 스키마 검증 후 확인 화면을 표시합니다.
- 병합: 동일 세션 내용이면 중복 제거; 같은 ID·다른 내용이면 전체 병합 거절. 카드 충돌은 updatedAt 최신본 사용. 기존 설정 유지.
- 교체: 명시적으로 ‘교체’를 입력한 뒤 전체 데이터·설정을 변경합니다.
- 초기화: ‘초기화’ 입력 확인. 자동 삭제 없음.
- 최대 세션 5,000개·카드 2,000장. 한도 초과 시 명시적 실패, 백업/삭제로 관리.

`migrate`는 v1을 검증하고 미래 버전을 거절합니다. 향후 v2를 도입할 때 v1→v2 순수 변환과 테스트를 추가하고 원본을 보존하세요. 현재 가짜 v0는 없습니다. 개인 정보 서버 전송이나 동기화는 없습니다.
