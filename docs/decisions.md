# 요구사항 개선 및 구현 범위

사용자의 최신 요청에 따라 8주 일정, 주 4회 프로그램, 기초·4주·8주 평가를 모두 제거했습니다. 훈련 자체를 지속적으로 반복하고 난이도·기록을 이어가는 제품입니다. 대시보드의 최근 28일 활동은 관찰 창일 뿐 종료 기간이 아닙니다.

## 기존 사용자 저장소에서 참고한 점

- `chronopilferer/monitering_front`: package.json의 React 19/TypeScript/Vite/Zod를 확인하고 동일한 개발 기반을 채택. App.tsx의 pages 분리, main.tsx의 ErrorBoundary 구조를 참고. 기존 BrowserRouter는 Pages 하위 경로 새로고침을 위해 HashRouter로 변경. SSE·알람·서버 관련 구조는 가져오지 않음.
- `chronopilferer/blog`: Next/React 및 MUI 의존성을 확인. 이번 앱은 서버 렌더링이나 콘텐츠 파이프라인이 필요 없어 Vite를 선택. 기존 코드를 복사하지 않음.
- 일부 기타 저장소의 README 요청은 404였으며 그 내용을 추정하지 않음.

## 명확히 보완한 정책

- N-back 목표/비목표를 확보하고 우발적 일치를 방지, 첫 N개 채점 제외.
- 탭 숨김·수동 일시정지는 중단 처리 후 새 세션으로 재시작. 휴식 시간과 재노출로 인한 점수 왜곡 방지.
- 같은 설정/입력/알고리즘끼리 차트 비교. 총 IQ 점수 없음.
- 백업 충돌 보수적 거절, 교체 명시 확인, 손상 원본 보존, 용량 실패 표시.
- 과제 엔진·UI·저장 계약 분리. 기능 폴더의 공개 index를 통해 등록.

## 현재 범위와 후속 확장

동작 구현: 여섯 주요 과제, 연습·정식·결과, 자동 난이도, 기록/차트, 카드 CRUD/복습, 장소 사용자화, 백업/복원, 라이트·다크, 반응형.

선택 확장으로 남김: 청각/Dual N-back, 순서 외의 추론 생성기, 30초보다 긴 지연 회상과 알림, IndexedDB, 다중 기기 동기화. 8주 프로그램과 정기 평가는 제거된 요구사항으로 재도입하지 않습니다.

자동 난이도는 개인용 운영 기준이며 실제 인지능력이 지속적으로 상승한다고 보장하지 않습니다.

## 2026-11-15 로직 재검토 (규칙 버전 2)

수정한 문제:

- N-back/Running Span 연속 동일 자극 사이에 명시적인 빈 구간을 삽입. 설정한 전체 시행 간격은 유지하며 N-back은 빈 구간에도 응답 가능.
- N-back 연습에서 시행별 판정 피드백 후 다음 자극으로 진행. 준비 구간은 계속 채점 제외.
- 기억 추론은 조건 암기와 응답을 분리. 정식은 15초 후, 연습은 명시적인 기억 완료 후에만 응답 가능. 누락된 이름으로 관계 조건을 만족시키는 판정도 방어.
- Complex Span의 오답 산술식이 항상 실제값보다 크던 편향 제거. 홀수 문제 수의 참/거짓 다수 방향도 무작위화. 계산 타임아웃은 오답.
- 회상에서 모르는 자리를 명시적으로 비우고 이후 항목의 위치를 유지. Complex Span/궁전의 항목별 정답 피드백 추가.
- 궁전 정식 암기는 장소별 설정 시간으로 자동 전환. 연습만 자율 시간. 장소 수를 넘는 자동 레벨 상승 방지.
- 난이도 조절은 최근 연속 완료 기록 두 개만 검사하고 입력 방식과 규칙 버전도 일치시킴. 중간에 다른 조건의 정식 기록이 있으면 오래된 성공 기록과 묶지 않음.
- 복습은 기한이 오래 지난 카드 우선. '어려움'도 학습 단계를 0으로 되돌려 짧은 간격부터 재학습. 복습 대상이 없으면 재시작 대신 설정으로 이동.
- 저장 중 재시작 차단. 탭 숨김/일시정지 이후 늦게 도착한 완료 콜백은 무시.

기존 알고리즘 버전 1 기록은 삭제하지 않음. 신규 기록은 버전 2이며 차트와 난이도 조절에서 기존 기록과 섞지 않음. 데이터 외형은 스키마 v1을 유지하고 algorithmVersion 허용값만 1|2로 확장.
